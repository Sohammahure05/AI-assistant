# AI Assistant (JARVIS)

A personal AI assistant built in phases — from a text-based skill system
to a voice-controlled agent with memory, an LLM brain, and a security layer.

## Roadmap

- [x] **Phase 0** — Project setup: packaging, config, logging, git
- [ ] **Phase 1** — Text interface + skill/plugin architecture
- [ ] **Phase 2** — Hybrid router (deterministic + LLM)
- [ ] **Phase 3** — Short-term + long-term memory
- [ ] **Phase 4** — Voice: TTS → STT → push-to-talk → wake word
- [ ] **Phase 5** — Killer skills: system control, morning briefing, dashboard
- [ ] **Phase 6** — Security layer: permissions + audit log
- [ ] **Phase 7** — Demo video + architecture diagram
